## Lessons Learned

### What Went Well
1. Clear role definition and responsibility allocation
2. Regular team meetings ensured coordination
3. Early prototyping identified design issues early
4. Comprehensive testing prevented last-minute issues
5. Good documentation practices aided understanding

### Challenges Faced
1. Initial complexity in understanding many-to-many relationships
2. Oracle SQL syntax differences from other SQL dialects
3. Balancing normalization with query performance
4. Coordinating parallel work streams effectively

### Recommendations for Future Projects
1. Allocate more time for requirements analysis
2. Start testing earlier in the development cycle
3. Create a shared code repository from day one
4. Schedule regular code review sessions
5. Maintain a centralized question/answer log
